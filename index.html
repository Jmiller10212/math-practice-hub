How scoring & saving work

Each problem counts once when you first check a complete set of answers. A perfect first try means the whole answer was correct on that first check. You can fix mistakes and check again; solving a problem after a retry still increases “Solved.” Unchecked problems do not count. Scores are separate for each activity and difficulty, for each decomposition mode, and for each top/bottom size combination in Multiplication. In the Decimal Place Value Quiz and both Decomposing games, choosing an answer immediately scores the question; a correct choice also increases “Solved.”

Keep using this file in the same browser and location for consistent access to saved progress. Private browsing, clearing browser data, or moving the file may affect saved scores. No information is sent anywhere.
